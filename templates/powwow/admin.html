Place your blocks

In Cannon’s Blocks area, select Pow Wow → Important Date and place it in event-details. Select Pow Wow → Countdown and place it in countdown for the homepage hero, or in sidebar for an inner page.

Use the plain block template and leave the placement title blank to avoid an empty wrapper after the event. Assign public visibility if everyone should see the block.
